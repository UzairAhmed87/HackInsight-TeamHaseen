      09 / PROVENANCE

      Sources & limitations

      PAQI Karachi daily PM2.5 dataset

      Open pinned dataset record ↗CC BY 4.0 licence ↗

      • Historical gold table ends 2024-12-31; it is not a live feed.
      • Live AirGradient cards are neighbourhood point sensors, not citywide exposure.
      • Orangi Pilot Project is not claimed live until its public API identity returns verified readings.
      • Outputs are informational, not medical or regulatory advice.

      U.S. Consulate General Karachi PM2.5 monitor (hourly)

      Open OpenAQ location record ↗

      • This monitor stopped publishing on 2025-03-04; it is a historical reference series, not a live feed.
      • PAQI does not document its input monitors, so agreement is measured rather than assumed to be independence.
      • PAQI's day boundary is unpublished; Consulate days are Asia/Karachi local days.

      The Urban Unit AirGradient network, Karachi (hourly, live)

      Open OpenAQ explorer ↗

      • Low-cost optical sensors without humidity correction; levels are not equivalent to the reference monitor.
      • Hourly values are OpenAQ aggregates of raw sensor readings; missing sensor-hours are not filled.
